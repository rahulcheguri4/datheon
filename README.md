
# Personal Developer Portfolio & Project Showcase

## 📌 Project Overview

This project is a responsive Personal Developer Portfolio Website designed to showcase my technical skills, projects, resume, and contact information.

The portfolio provides a professional online presence and helps recruiters and visitors learn more about my development skills and projects.

## 🎯 Objectives

- Create a modern and professional developer portfolio.
- Showcase technical skills and completed projects.
- Provide resume download functionality.
- Add contact information and social media links.
- Implement responsive design for mobile, tablet, and desktop.
- Include dark and light theme functionality.
- Deploy the portfolio website online.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Flexbox
- CSS Grid
- Responsive Media Queries

## ✨ Features

- Responsive portfolio design
- Home section with introduction
- About Me section
- Technical Skills section
- Featured Projects section
- Project details popup
- Resume download button
- Contact information
- Dark and Light mode toggle
- Mobile hamburger navigation
- Smooth scrolling
- Modern user interface

## 🚀 How to Run the Project

### Step 1: Download or Clone the Repository

```bash
git clone https://github.com/yourusername/developer-portfolio.git
```

### Step 2: Open the Project Folder

```bash
cd developer-portfolio
```

### Step 3: Run the Website

Open the `index.html` file in your web browser.

No backend server or database is required.

## 💻 Project Sections

### Home
Introduces the developer with a name, professional role, and navigation buttons.

### About Me
Provides a short professional introduction and career information.

### Skills
Displays technical skills such as HTML, CSS, JavaScript, Python, Flask, and SQL.

### Projects
Showcases development projects with descriptions and interactive project details.

### Resume
Allows visitors to download the developer's resume.

### Contact
Provides email, LinkedIn, and GitHub links.

## 📱 Responsive Design

The website is designed to work on:

- Desktop computers
- Tablets
- Mobile phones

CSS media queries are used to adjust the layout for different screen sizes.

## 🌐 Deployment

The portfolio can be deployed using:

- GitHub Pages
- Netlify
- Vercel

After deployment, the live website URL can be shared with recruiters and employers.
